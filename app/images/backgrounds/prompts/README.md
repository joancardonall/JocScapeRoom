# Prompts per generar fons

Guarda aqui els prompts utilitzats per generar cada fons.

Recomanacio:

```text
desk-noir.md
desk-laboratori.md
desk-arxiu.md
```

Idealment cada prompt hauria d'indicar:

- proporcio 16:9
- vista frontal o lleugerament zenital
- objectes clicables visibles
- espai clar per a ordinador, tauler, carpeta, calaix i bossa de proves
- estil visual concret
