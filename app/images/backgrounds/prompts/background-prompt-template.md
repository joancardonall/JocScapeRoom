# Prompt template

Genera una escena de joc de detectius en format 16:9, resolucio 1920x1080, amb una composicio clara i llegible per a una web interactiva.

L'escena ha d'incloure aquests objectes clicables, ben visibles i separats:

- ordinador o pantalla
- tauler de sospitosos o proves
- carpeta principal del cas
- calaix o zona de notes
- bossa de proves forenses

Estil visual:

```text
DESCRIU AQUI L'ESTIL: noir, laboratori, arxiu antic, mansio, etc.
```

Restriccions:

- sense text llegible a la imatge
- sense persones en primer pla
- sense objectes importants tapats
- llum suficient per distingir els elements
- composicio estable, no massa carregada
- fons pensat per tenir hotspots invisibles a sobre
