# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 38 anys, atractiu sense artifici, barba curta, ulls foscos observadors, camisa blanca arremangada i armilla negra de servei, llum calida de cuina noble i passadissos antics, rastre de cansament i tristesa, presencia propera pero amb una ambiguitat inquietant, estil de drama criminal europeu.
