# Prompt d'Imatge

Retrat cinematic realista d'una dona catalana de 31 anys, faccions delicades i mirada molt concentrada, cabell arrissat recollit de manera informal, pell pallida amb petites marques de cansament, bata o roba de treball elegant tacada lleument de pols de paper, llum lateral d'arxiu i taller, ambient historic amb textures de pergami i fum, vulnerabilitat i inteligencia visibles alhora.
