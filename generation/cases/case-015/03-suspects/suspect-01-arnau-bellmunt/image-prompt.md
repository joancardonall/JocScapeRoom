# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 58 anys, elegant i contingut, cabell platejat molt ben pentinat, ulls cansats pero dominants, vestit de llana fosca impecable, ambient de fundacio privada d'arquitectura amb marbre, vidre i llum de capvespre, aura de mecenes poderos i discret.
