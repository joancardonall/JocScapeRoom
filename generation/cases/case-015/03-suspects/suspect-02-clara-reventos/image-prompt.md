# Prompt d'Imatge

Retrat cinematic realista d'una dona catalana de 39 anys, restauradora de vidre i metall, rostre fi i tens, cabell recollit sense ornaments, ulleres de treball penjades del coll, mans marcades per taller, roba fosca funcional amb elegancia austera, fons de laboratori de conservacio amb peces de niquel i fragments de vidre gravat.
