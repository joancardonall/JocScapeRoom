# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 34 anys, escenograf contemporani, guapo pero desfet per l'ansietat, cabell negre desordenat, americana fosca sobre jersei fi, ulls molt vius, ambient de control tecnic amb monitors, boira artificial i reflexos de vidre, energia creativa i desesperada.
