# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 56 anys, mecenes i tresorer, elegancia cara pero nerviosa, cabell gris impecable, ulls cansats i calculadors, vestit fosc de llana fina, ambient de salo blau d'una fundacio historicista amb vellut, marbre i llum d'aram, aura de poder institucional i por reputacional.
