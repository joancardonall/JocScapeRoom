# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 33 anys, dissenyador de llum i boira, atractiu cansat i nervios, cabell fosc lleugerament desordenat, jersei fi sota americana negra, ulls molt vius amb orgull ferit, ambient de cabina tecnica amb controls de llum, boira subtil i reflexos de mirall, energia creativa sota pressio.
