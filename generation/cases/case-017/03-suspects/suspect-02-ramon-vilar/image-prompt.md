# Prompt d'Imatge

Retrat cinematic realista d'un home catala de 58 anys, patro i mecenes, elegancia afable i calculadora, cabell gris ben pentinat, vestit fosc impecable, ulls suaus pero estrategics, ambient de vestIbul institucional vinculat a la Sagrada Familia amb fusta noble, llum calida i discreta opulencia, sensacio de prestigi i autoproteccio.
