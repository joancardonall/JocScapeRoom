# Sospitos del Cas

Cada sospitos te una carpeta propia amb els materials base que despres es convertiran en proves o declaracions dins del joc.

Els `image-prompt.md` han de demanar sempre retrats policials de fitxa: bust frontal, cap i espatlles, mirant directament a camera, fons neutre, sense accio, sense mans visibles, sense objectes i sense escena narrativa.
